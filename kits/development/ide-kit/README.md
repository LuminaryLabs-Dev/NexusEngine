# IDE host

Explicit optional Node host; never loaded by portable Core defaults. Composes Authoring Project/Code, selected Build toolchains, bounded process execution and a visible loopback editor. `createIdeHost({projectRoot,stateRoot,authorize})` requires an external state directory and explicit host authorization. `serveIde(host)` returns a local URL and close method. Commands consume source snapshots; source saves guard external changes. UTF-8 and original newlines are retained. Source save-all can fail partway across filesystem files; atomic multi-document refactoring is a Project transaction, not a filesystem transaction.

TypeScript supplies diagnostics, completions, hover, definitions, references, symbols and formatting for JS/TS. Other languages return explicit unavailable results until a language provider is configured. `createStdioProtocol` connects configured LSP/DAP executables with bounded framing, correlation, timeouts and disconnect failures; it does not install or pretend to provide a language server/debugger. Debug commands, noninteractive terminal argument arrays and read-only Git status/diff are host-authorized APIs. The first visible editor exposes source/edit/save/build/run, intelligence and Git; an interactive PTY and full debugger widgets are outside this initial host surface.

The IDE never installs missing tools or changes source dependencies automatically. C# and embedded QuickJS/Web profiles remain explicit blockers until their executable/package providers are supplied and validated. This is not the separate Nexus JavaScript-to-Rust compiler expansion.
