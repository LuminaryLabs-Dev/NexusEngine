# Engine production host

Optional Node host over existing Agent, Runtime, Authoring, Asset, MCP and Build APIs. Import `createEngineProductionHost` from `nexusengine/kits/agent/production`. Bind an existing workspace with explicit writable scope; pass `agentId` and an authorization callback when integrating an agent. `dependencies` may identify a host module URL from which optional Playwright/Three dependencies resolve.

`host.call("production.discover")` lists native operations and versioned workflows. All `production.*` connection tools are also registered with the Engine MCP service. The Codex plugin preserves `kit_*` names as wrappers. Full results are durable; `host.readReceipt(id)` retrieves an archived result. `host.workflows` is the Core Agent registry. Concrete recipes are optional authoring examples, not Core geometry algorithms or quality guarantees.

Commit persists before observer delivery, acknowledges after successful delivery, and does not tick simulation. Observer failure retains pending mutations; delivery can repeat. A host with failed commit/storage is stopped until close/recovery. Cancellation is checked before dispatch. In-flight external effects still require reconciliation; no exactly-once guarantee is claimed for arbitrary providers.

Checkpoint v2 stores immutable document version references, archived history references and compact workflow state. Full receipts are stored separately with a bounded hot cache. V1 migration preserves original checkpoint bytes; missing/corrupt blobs fail closed. Keep the object store with its checkpoint. Filesystem portable Authoring saves now pull archived history and receipts one record at a time, stream document objects and checkpoint JSON to staged files, and replace the generation-guarded manifest last. V1 package bytes and independent portability remain compatible. Additional save memory scales with the largest document/history record plus compact reference metadata, rather than all retained geometry. Explicit in-memory snapshots, non-streaming storage providers and portable loading still materialize data and retain their existing byte budgets. Count limits still apply to retained Authoring history and session turns.

Browser rendering stays in this optional provider and never enters portable Core imports. Focus resolves source dependencies before export. Numeric image comparison never supplies aesthetic acceptance. Agent/human image review remains explicit.
