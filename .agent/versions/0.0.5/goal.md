The active execution order is source-first. The isolated bulk implementation
pass has attempted every remaining dependency-ordered feature without claiming
proof. Each following turn now reviews, integrates, and repairs a bounded set
iteratively until all detailed requirements are observed and validated.


no package is promoted to completed. A package becomes complete only during the
review phase after its required checks pass. Bulk generation never authorizes
repository mutation outside the active branch, matrix completion, push,
publication, or protected-ref changes.
