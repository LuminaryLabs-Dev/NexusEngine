# Authoring foundation contract, revision 1

Authoring owns editable source, distinct from published Object/Asset identities, Presentation descriptors and Runtime playback. Project is the single commit authority and owns portable document envelopes, typed-operation registration, atomic transactions, retained receipts, undo/redo deltas, fresh revisions and epochs, preview acceptance and source snapshots. Existing generic Runtime transaction helpers cannot atomically validate/commit related typed documents or preserve attribute mappings; reuse Foundation canonical SHA-256 and normal Engine Kit installation without introducing another Runtime. Engine ECS resource storage holds the authoritative project. Typed children receive a scoped staging transaction and immutable queries. No user callback is deserialized from project source.

Public identities: authoring-domain-contract-kit / n:authoring / authoring; authoring-project-document-kit / n:authoring:project / authoringProject; authoring-mesh-document-kit / n:authoring:mesh / authoringMesh; authoring-editing-session-kit / n:authoring:editing / authoringEditing. Imports: nexusengine/domains/authoring and its contract/project/mesh/editing subpaths. These are new source-backed identities, pending proof until executed.

Project commands carry requestId, epoch and 1-256 typed operations. Edits/deletions require the pre-transaction document revision. Replay checks retained request hashes before applying work. Resets start a new epoch without rewinding revision clocks. Restores validate full source and history before replacement, allocate fresh current revisions/epoch, and retain historical receipts for identical retry. Small edits share unchanged immutable document contents and history deltas; snapshots intentionally copy portable source. Receipt capacity fails explicitly rather than silently evicting retry protection. Source dependencies are acyclic; supported initial typed schemas use latest references. Exact references require a typed rebase implementation and cannot be silently rewritten. Public snapshots preserve history content chains; all types must be installed before loading source.

Mesh owns topology/attributes and typed modeling operations; Editing owns selection documents referencing Mesh and disposable previews, committed through Project. First proof: cube -> face selection -> transform -> inspection -> preview/accept -> undo/redo -> save/load -> retained retry and deterministic replay. Invalid input, stale epochs/revisions, missing dependencies, topology invalidity and corrupted history fail before commit. Prove direct helpers and installed paths before generation, then repeat through manifest-backed public package entrypoints.

Allowed mutation: Authoring source, source-backed manifests, public barrel/exports via standard generators, focused tests/runner, root AUTHORING.md and active docs. Host/storage/renderer/codec providers remain external. Every later capability family needs its own supported schema/algorithm and meaningful proof; the foundation does not establish them.
