# Cycle 011 Goal

Complete the dependency-ready `n:render:contracts` master package as one
bounded, evidence-backed batch. Establish canonical Render execution identity
without moving renderer-neutral meaning out of Presentation or placing a
concrete renderer, GPU API, host surface, shader compiler, or frame executor in
Core contracts.

This cycle covers exactly 49 detailed actions across seven atomic Kits:

- `render-domain-contract-kit`
- `render-provider-contract-kit`
- `render-resource-schema-kit`
- `render-frame-schema-kit`
- `render-pass-schema-kit`
- `shader-schema-kit`
- `render-event-schema-kit`

No provider implementation, browser integration, The Open Above mutation,
push, release branch, or protected-ref change belongs to this cycle.
