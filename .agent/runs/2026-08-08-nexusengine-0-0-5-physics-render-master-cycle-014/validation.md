and Asset cache providers. Device Memory owns capability-bound byte capacity
and reservations; Device Queue owns logical submission completion. Core Render
Resource owns portable execution-resource identity, references, lifecycle
state, semantic residency records, cache indexes, admission-to-device-reservation
mapping, and integrity results. Concrete providers own GPU handles, real
allocation, command execution, upload, release, repair, and cache eviction.
