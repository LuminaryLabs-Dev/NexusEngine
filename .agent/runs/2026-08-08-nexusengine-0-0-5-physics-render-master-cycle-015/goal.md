# Cycle 015 Goal

Complete the dependency-ready `n:render:buffer` master package as one bounded,
evidence-backed batch. Establish portable Buffer resource descriptors, explicit
layouts, semantic Vertex/Index/Uniform/Storage/Instance/Indirect views, and
provider-neutral update receipts.

This cycle covers exactly 56 detailed actions across eight atomic Kits:

- `buffer-resource-kit`
- `vertex-buffer-kit`
- `index-buffer-kit`
- `uniform-buffer-kit`
- `storage-buffer-kit`
- `instance-buffer-kit`
- `indirect-buffer-kit`
- `buffer-layout-kit`

Asset byte storage and decoding, Render Resource identity and residency, Device
capacity and queue completion, GPU handles, actual allocation, mapping, upload,
provider execution, Geometry ownership, Texture ownership, browser rendering,
The Open Above mutation, push, release branches, and protected-ref changes are
outside this cycle.
