# Cycle 017 Goal

Complete the dependency-ready `n:render:shader` master package as one bounded,
evidence-backed batch. Establish portable Shader language, source, include,
module, program, reflection, variant, permutation, compile, error, and cache
state while keeping executable compilation and backend programs external.

This cycle covers 91 detailed actions across thirteen planned Kit rows. Twelve
new Shader Kits may be implemented. The planned `shader-schema-kit` row must
reuse the existing canonical Kit under `n:render:contracts`; creating a second
Kit with that identity is forbidden.

Presentation shader meaning, Material and Pipeline binding, provider parsing
and compilation, executable binaries, GPU handles, concrete renderer behavior,
The Open Above mutation, browser proof, push, release branches, and protected
ref changes are outside this cycle.
