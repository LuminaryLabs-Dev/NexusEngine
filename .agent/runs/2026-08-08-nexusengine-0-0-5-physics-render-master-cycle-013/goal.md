# Cycle 013 Goal

Complete the dependency-ready `n:render:device` master package as one bounded,
evidence-backed batch. Establish portable Render device identity, feature and
limit negotiation, capability profiles, memory accounting, logical queues,
device lifecycle, loss records, and read-only diagnostics.

This cycle covers exactly 63 detailed actions across nine atomic Kits:

- `render-device-contract-kit`
- `device-feature-kit`
- `device-limit-kit`
- `device-capability-kit`
- `device-memory-kit`
- `device-queue-kit`
- `device-lifecycle-kit`
- `device-loss-kit`
- `device-diagnostics-kit`

Concrete GPU handles, allocations, command encoding, queue execution, provider
repair, host surfaces, browser rendering, The Open Above mutation, push,
release branches, and protected-ref changes are outside this cycle.
