# 0.0.5 Physics Detection

`0.0.5` proves `n:physics:detection` as the canonical owner of deterministic broad-phase, spatial partition, dynamic-tree, sweep-and-prune, narrow-phase, GJK, EPA, continuous-collision, and normalized detection-result semantics.

## Ownership

Own provider-neutral broad-phase and narrow-phase collision classification without contact or solver behavior.

It owns:

- analytic primitive intersections
- convex GJK and EPA reference algorithms
- deterministic broad-phase pair generation
- linear sphere time of impact
- portable collision-detection outcomes
- portable spatial proxies and bounds

It does not own:

- body or collider lifecycle ownership
- constraint or impulse solving
- contact manifolds or trigger events
- gameplay collision reactions
- provider-native acceleration structures

## Atomic Kits

- `broad-phase-kit`: Own canonical Detection discovery and deterministic broad-phase strategy selection.
- `broad-phase-pair-kit`: Normalize, filter, deduplicate, and stably order broad-phase pairs.
- `continuous-collision-kit`: Compute exact linear sphere-sphere time of impact and reject unsupported sweep pairs.
- `dynamic-tree-kit`: Build and query deterministic immutable AABB trees from portable proxies.
- `epa-penetration-kit`: Expand an intersecting GJK simplex into deterministic convex penetration witnesses.
- `gjk-detection-kit`: Determine convex support-shape separation or intersection with deterministic GJK simplex evolution.
- `narrow-phase-kit`: Dispatch supported analytic and convex algorithms into one portable collision result.
- `collision-detection-result-kit`: Normalize finite portable collision results and stable result ordering.
- `shape-intersection-kit`: Resolve exact analytic primitive and convex-plane shape intersections.
- `spatial-partition-kit`: Own exact-once portable broad-phase proxy records and deterministic bounds queries.
- `sweep-and-prune-kit`: Generate deterministic broad-phase pairs by sorted-axis interval sweeping.

## Proof

Direct behavior, lifecycle/composition where applicable, failure handling, portability, and backend-boundary behavior are exercised by `tests/core-domains/core-physics-detection-smoke.mjs`.

The Core records remain provider-neutral: concrete Rapier, PhysX, Three.js, WebGL, WebGPU, native-window, and GPU-resource handles stay outside this semantic boundary.
