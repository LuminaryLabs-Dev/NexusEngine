# 0.0.5 Render Surface

`0.0.5` proves `n:render:surface` as the canonical owner of portable window/offscreen/swapchain surface descriptors, viewports, scissors, resize/fullscreen intents, and surface-format state without host or GPU handles.

## Ownership

Own portable output-surface descriptors, logical regions, format choices, and deterministic transition intents.

It owns:

- exact-once descriptor lifecycle records
- portable surface identities and dimensions
- resize and fullscreen intents
- surface format selections
- viewport and scissor regions
- window, offscreen, and swapchain descriptors

It does not own:

- DOM elements or native window handles
- GPU swapchains or backend resources
- Presentation graph ownership
- frame encoding, submission, or presentation
- provider execution or platform transitions

## Atomic Kits

- `surface-format-kit`: Own portable color, depth, alpha, sample, and HDR surface format selections.
- `fullscreen-kit`: Own portable fullscreen enter and exit intents without platform execution.
- `offscreen-surface-kit`: Own portable offscreen layer, sample, and usage policy while base Surface owns dimensions.
- `render-surface-kit`: Own portable base Render surface descriptors and exact-once lifecycle records.
- `resize-kit`: Own portable resize intents without mutating host or provider surfaces.
- `scissor-kit`: Own bounded portable scissor regions without issuing provider commands.
- `swapchain-surface-kit`: Own portable swapchain requests without creating GPU swapchains or provider handles.
- `viewport-kit`: Own bounded portable viewport regions and depth ranges.
- `window-surface-kit`: Own portable window-surface descriptors without host window handles or platform transitions.

## Proof

Direct behavior, lifecycle/composition where applicable, failure handling, portability, and backend-boundary behavior are exercised by `tests/core-domains/core-render-surface-smoke.mjs`.

The Core records remain provider-neutral: concrete Rapier, PhysX, Three.js, WebGL, WebGPU, native-window, and GPU-resource handles stay outside this semantic boundary.
