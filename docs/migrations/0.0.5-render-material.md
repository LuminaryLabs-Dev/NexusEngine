# 0.0.5 Render Material

`0.0.5` adds the provider-neutral Material package at `n:render:material`. It
owns portable associations between exact Shader interfaces, parameter values,
Texture views, samplers, instances, variants, validation records, and semantic
cache lineage. It does not own authored visual meaning, GPU binding objects,
draw submission, Shader compilation, Texture allocation, or provider repair.

## Complete Import

```js
import { createEngine } from "nexusengine";
import { createRenderContractsDomain } from "nexusengine/domains/render/contracts";
import { createRenderLifecycleDomain } from "nexusengine/domains/render/lifecycle";
import { createRenderDeviceDomain } from "nexusengine/domains/render/device";
import { createRenderResourceDomain } from "nexusengine/domains/render/resource";
import { createRenderBufferDomain } from "nexusengine/domains/render/buffer";
import { createRenderTextureDomain } from "nexusengine/domains/render/texture";
import { createRenderShaderDomain } from "nexusengine/domains/render/shader";
import { createRenderMaterialDomain } from "nexusengine/domains/render/material";

const engine = createEngine({
  kits: [
    ...createRenderContractsDomain(),
    ...createRenderLifecycleDomain(),
    ...createRenderDeviceDomain(),
    ...createRenderResourceDomain(),
    ...createRenderBufferDomain(),
    ...createRenderTextureDomain(),
    ...createRenderShaderDomain(),
    ...createRenderMaterialDomain()
  ]
});
```

## Atomic Imports

| Capability | Public import | Ownership |
| --- | --- | --- |
| Contract | `nexusengine/domains/render/material/contract` | Portable Material schemas and provider boundary |
| Binding | `nexusengine/domains/render/material/binding` | Exact Material-slot to Shader-interface association |
| Parameter | `nexusengine/domains/render/material/parameter` | Typed parameter values for one binding |
| Texture binding | `nexusengine/domains/render/material/texture-binding` | Exact resident Texture view and subresource requirements |
| Sampler binding | `nexusengine/domains/render/material/sampler-binding` | Portable sampler descriptors assigned to sampler slots |
| Instance | `nexusengine/domains/render/material/instance` | Complete required-slot composition |
| Variant | `nexusengine/domains/render/material/variant` | Instance overrides paired with one Shader variant |
| Validation | `nexusengine/domains/render/material/validation` | Exact current compile, reflection, and composition proof |
| Cache | `nexusengine/domains/render/material/cache` | Validated Material-to-resident-Resource lineage |

## Execution Contract

A Material binding names one exact Shader program and declares every selected
slot with matching coordinates, kind, value type, and stage visibility. Empty,
partial, or extra stage visibility is rejected. Parameter, Texture, and sampler
records must belong to that binding, and an instance must cover every required
slot exactly once.

Texture bindings name exact typed views and required mip/layer subresources.
Registration and every current instance resolution recheck the Texture resource
lifecycle and subresource residency. If a required subresource is evicted, the
stored Material records remain unchanged, but dependent validation becomes
stale and cache registration or reuse fails until a new current composition is
validated.

Validation binds an instance or Material variant to one completed Shader
compile and matching reflection record. Its composition hash includes the
target, binding, parameters, Texture and sampler records, compile source
closure and artifact integrity, and reflection. A cache entry additionally
requires a resident Render Resource of kind `material` whose descriptor names
the same validation and composition hash.

Every mutation requires an `operationId`. Exact replay returns the original
receipt, changed content under the same operation ID fails before mutation,
queries are read-only, snapshots are strict JSON-portable clones, and repeated
reset or load is stable. There are no root forwarding exports, implicit Kit
installation, provider execution, or legacy snapshot coercion.
