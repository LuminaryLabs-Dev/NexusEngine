# 0.0.5 Render Buffer

`0.0.5` adds the provider-neutral logical Buffer package at
`n:render:buffer`. It owns exact logical Buffer descriptors, explicit portable
field layouts, semantic typed views, bounded update requests, and provider
update receipts. It does not own source bytes, GPU handles, allocation,
mapping, byte transfer, queue execution, or provider repair.

## Complete Import

```js
import { createEngine } from "nexusengine";
import { createRenderContractsDomain } from "nexusengine/domains/render/contracts";
import { createRenderLifecycleDomain } from "nexusengine/domains/render/lifecycle";
import { createRenderDeviceDomain } from "nexusengine/domains/render/device";
import { createRenderResourceDomain } from "nexusengine/domains/render/resource";
import { createRenderBufferDomain } from "nexusengine/domains/render/buffer";

const engine = createEngine({
  kits: [
    ...createRenderContractsDomain(),
    ...createRenderLifecycleDomain(),
    ...createRenderDeviceDomain(),
    ...createRenderResourceDomain(),
    ...createRenderBufferDomain()
  ]
});
```

## Atomic Imports

| Capability | Public import | Ownership |
| --- | --- | --- |
| Logical Buffer | `nexusengine/domains/render/buffer/resource` | Exact logical Buffer descriptors, revisions, update requests, and provider receipts |
| Layout | `nexusengine/domains/render/buffer/layout` | Portable member formats, offsets, alignments, and stride |
| Vertex | `nexusengine/domains/render/buffer/vertex` | Layout-backed Vertex Buffer views |
| Index | `nexusengine/domains/render/buffer/index` | Typed Index Buffer views |
| Uniform | `nexusengine/domains/render/buffer/uniform` | Layout-backed Uniform Buffer ranges and dynamic alignment |
| Storage | `nexusengine/domains/render/buffer/storage` | Access-qualified Storage Buffer element ranges |
| Instance | `nexusengine/domains/render/buffer/instance` | Layout-backed Instance Buffer views |
| Indirect | `nexusengine/domains/render/buffer/indirect` | Draw, indexed-draw, and dispatch command ranges |

## Ownership Boundary

Buffer records refer to an exact resident Render Resource revision. Dynamic or
stream updates must refer to a matching pending Device queue submission, and
completion must provide a matching completed submission and explicit provider
receipt. Immutable Buffers reject updates.

Resource owns execution-resource identity and residency. Device owns logical
queue completion. Asset owns source bytes and content identity. Geometry and
Texture own higher-level mesh and image meaning. Concrete providers own GPU
handles, allocation, mapping, byte transfer, command submission, and repair.

Every mutation requires an `operationId`. Exact replay returns the original
receipt, changed content under the same operation ID fails before mutation,
queries are read-only, snapshots are strict and JSON-portable, and repeated
reset or load is stable. Layouts reject overlapping members, duplicate shader
locations, invalid alignments, and out-of-range views before mutation.

There are no root forwarding exports, backend objects, implicit uploads,
source-byte copies, or compatibility aliases.
