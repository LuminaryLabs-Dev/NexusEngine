# 0.0.5 Physics World Domain

`0.0.5` introduces the canonical provider-neutral physical environment owner
at `n:physics:world`. No previous canonical NexusEngine Physics World package
path is retained or forwarded.

The frozen ProtoKit wind field and product airstream implementations are source
evidence, not compatibility APIs. Their reusable physical flow semantics are
represented by strict field records. Weather authority, authored routes,
renderer effects, body response, and product state remain outside this domain.

## Complete Import

```js
import { createEngine } from "nexusengine";
import { createPhysicsContractsDomain } from "nexusengine/domains/physics/contracts";
import { createPhysicsWorldDomain } from "nexusengine/domains/physics/world";

const engine = createEngine({
  kits: [
    ...createPhysicsContractsDomain(),
    ...createPhysicsWorldDomain()
  ]
});
```

## Atomic Imports

| Capability | Public import | Ownership |
| --- | --- | --- |
| World Registry | `nexusengine/domains/physics/world/registry` | Immutable Physics world identity and capability references |
| World Settings | `nexusengine/domains/physics/world/settings` | Coordinates, units, bounds, and out-of-bounds policy |
| Gravity Field | `nexusengine/domains/physics/world/gravity-field` | Uniform and point-gravity acceleration |
| Force Field | `nexusengine/domains/physics/world/force-field` | Non-gravity force and acceleration fields |
| Wind Field | `nexusengine/domains/physics/world/wind-field` | Physical flow velocity, density, and turbulence descriptors |
| Time Scale | `nexusengine/domains/physics/world/time-scale` | Physics-only delta scaling |
| Simulation Region | `nexusengine/domains/physics/world/simulation-region` | Physical simulate, sleep, and disable selection |

## World Definition

```js
engine.n.physicsSimulationRegion.defineRegion({
  operationId: "region:define:active",
  region: {
    id: "region:active",
    shape: "aabb",
    minimum: [-1000, -100, -1000],
    maximum: [1000, 2000, 1000],
    behavior: "simulate"
  }
});

engine.n.physicsGravityField.defineField({
  operationId: "gravity:define:earth",
  field: {
    id: "gravity:earth",
    kind: "uniform",
    vector: [0, -9.81, 0],
    regionIds: ["region:active"]
  }
});

engine.n.physicsWindField.defineField({
  operationId: "wind:define:corridor",
  field: {
    id: "wind:corridor",
    kind: "corridor",
    points: [[0, 200, 0], [2000, 400, 0]],
    speed: 12,
    radius: 100,
    edgeWidth: 20,
    regionIds: ["region:active"]
  }
});

engine.n.physicsWorld.defineWorld({
  operationId: "physics-world:define:main",
  world: {
    id: "world:main",
    gravityFieldIds: ["gravity:earth"],
    windFieldIds: ["wind:corridor"],
    simulationRegionIds: ["region:active"]
  }
});
```

Definitions are exact-once. Exact operation replay returns the original
receipt. Changed content under an accepted operation ID fails before mutation.
A second operation cannot replace an existing record ID with different
content. A Physics world cannot be defined or loaded with missing capability
references.

## Read-Only Sampling

```js
const sample = engine.n.physicsWorld.sample("world:main", {
  position: [50, 300, 0],
  timeSeconds: 12,
  deltaSeconds: 1 / 60
});
```

The result contains portable acceleration, force, wind velocity, region
resolution, bounds status, and scaled delta. Sampling does not change field,
region, scale, or world state and emits no semantic events.

## Ownership Cutover

- `n:world:weather` remains authoritative for authored weather and climate.
- `n:world:feature:atmosphere` remains authoritative for authored wind
  corridors, thermal columns, and other semantic atmosphere features.
- Physics Wind contains physical flow data only. It owns no particles,
  shaders, foliage animation, clouds, audio, or gameplay route state.
- Physics Time Scale transforms an explicit delta. Runtime owns clocks,
  schedules, and frame cadence; Lifecycle Step owns step requests.
- Simulation Region selects physical behavior. It does not replace semantic
  World regions, weather regions, trigger zones, or product areas.
- Bodies, colliders, contacts, broad phase, integration, and solving remain in
  their later canonical Physics packages. Concrete backend worlds and native
  handles remain provider-owned.

No historical `engine.windField` alias or old snapshot coercion is provided.
