# 0.0.5 Render Resource

`0.0.5` adds the provider-neutral Render execution-resource package at
`n:render:resource`. It owns portable identity, references, lifecycle state,
semantic accounting, integrity evidence, and provider operation receipts. It
does not decode assets, allocate GPU memory, encode commands, or execute a
renderer provider.

## Complete Import

```js
import { createEngine } from "nexusengine";
import { createRenderContractsDomain } from "nexusengine/domains/render/contracts";
import { createRenderLifecycleDomain } from "nexusengine/domains/render/lifecycle";
import { createRenderDeviceDomain } from "nexusengine/domains/render/device";
import { createRenderResourceDomain } from "nexusengine/domains/render/resource";

const engine = createEngine({
  kits: [
    ...createRenderContractsDomain(),
    ...createRenderLifecycleDomain(),
    ...createRenderDeviceDomain(),
    ...createRenderResourceDomain()
  ]
});
```

## Provider Boundary

Core records exact resource intent and validates portable provider receipts.
The Asset Domain owns source identity, decoded content, and content caches. The
Device Domain owns capability-bound memory capacity and logical queue
completion. Concrete providers own backend handles, allocation, upload,
release, eviction, repair, and command execution.

Every mutation requires an `operationId`. Exact replay returns the original
receipt. Changed content under the same operation ID fails before mutation.
Queries are read-only, snapshots are JSON-portable, declared source integrity
must be proved before upload, and active references prevent release.

There are no root forwarding exports, provider-object snapshots, implicit
provider calls, source-asset duplication, or compatibility aliases.
