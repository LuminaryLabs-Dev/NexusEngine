# 0.0.4 Domain Cutover

`0.0.4` removes the old Composition and Object package aliases. There are no
deprecated forwarding exports.

## Runtime Path Change

Use `n:object`. The legacy `n:core-object` path is removed. Shape, Fidelity,
Vegetation, and Placement are children of `n:object`; Tree, Foliage, and Ecology
are children of `n:object:vegetation`.

## MCP Composition

Install `createCoreMcpDomain()` and register
`createCompositionMcpProvider(...)` in the application. The host must resolve
trusted Kit factories, require human approval for `composition_apply`, persist
controller snapshots, and own the resulting runtime after MCP disconnects.
