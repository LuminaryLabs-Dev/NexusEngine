# 0.0.4 Semantic Domain Cutover

`0.0.4` is a hard cutover to manifest-owned semantic Domains. Removed imports,
identifiers, methods, and factories have no deprecated forwarding surface.

## Common Factory Renames

Remove the `Core` prefix and import the factory from its semantic owner:

```js
import { createDataKit } from "nexusengine/domains/runtime/data";
import { createObjectPlacementKit } from "nexusengine/domains/object/placement";
import { createPhysicsKit } from "nexusengine/domains/simulation/physics";
import { createGraphicsKit } from "nexusengine/domains/presentation/graphics";
```

Umbrella Domain factories are available from Domain entries such as
`nexusengine/domains/object`, `nexusengine/domains/runtime`, and
`nexusengine/domains/presentation`. Atomic imports are preferred when a consumer
does not need the whole family.

## Concrete Implementations

Core no longer ships concrete browser/native scene hosts, Three.js adapters,
shader registries, speech providers, model mocks, storage implementations,
terminal/repository tooling, authored sky presets, optional gameplay, or
complete games. Use the owner and reconstruction requirements in the generated
[root-module disposition ledger](0.0.4-root-module-dispositions.md).

## Composition And MCP

Install `createCompositionDomain()` and `createMcpDomain()` from their semantic
subpaths. Register `createCompositionMcpProvider(...)` with a transactional host
that supplies snapshot/restore, immutable source resolution, persistence, and
explicit authorization for `composition_apply`.
