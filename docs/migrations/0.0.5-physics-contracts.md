# 0.0.5 Physics Contract Foundation

Status: active `0.0.5` development. This page covers the contract package only;
it does not claim that the Physics solver or full domain cutover is complete.

## Canonical Ownership

`n:physics` now owns the canonical Physics domain identity.
`n:physics:contracts` owns six atomic contract Kits:

| Kit | Public import | API |
| --- | --- | --- |
| `physics-domain-contract-kit` | `nexusengine/domains/physics/contract` | `engine.n.physics` |
| `physics-provider-contract-kit` | `nexusengine/domains/physics/provider-contract` | `engine.n.physicsProviderContract` |
| `physics-state-schema-kit` | `nexusengine/domains/physics/state-schema` | `engine.n.physicsStateSchema` |
| `physics-command-schema-kit` | `nexusengine/domains/physics/command-schema` | `engine.n.physicsCommandSchema` |
| `physics-event-schema-kit` | `nexusengine/domains/physics/event-schema` | `engine.n.physicsEventSchema` |
| `physics-query-schema-kit` | `nexusengine/domains/physics/query-schema` | `engine.n.physicsQuerySchema` |

The aggregate entry is `nexusengine/domains/physics/contracts`.

## Installation

```js
import { createEngine } from "nexusengine";
import {
  createPhysicsCommandSchemaKit,
  createPhysicsDomainContractKit,
  createPhysicsEventSchemaKit,
  createPhysicsProviderContractKit,
  createPhysicsQuerySchemaKit,
  createPhysicsStateSchemaKit
} from "nexusengine/domains/physics/contracts";

const engine = createEngine({
  kits: [
    createPhysicsDomainContractKit(),
    createPhysicsProviderContractKit(),
    createPhysicsStateSchemaKit(),
    createPhysicsCommandSchemaKit(),
    createPhysicsEventSchemaKit(),
    createPhysicsQuerySchemaKit()
  ]
});
```

Install the root contract before child contracts. Composition resolves this
ordering automatically through the `n:physics` requirement.

## Boundary Changes

- `engine.n.physics` describes domain ownership and supported contract tokens;
  it no longer impersonates an installed provider.
- Provider validation is separate from provider installation and execution.
- State, command, event, and query records are strict JSON-portable schemas.
- Unknown top-level fields and nonportable values fail before mutation.
- No forwarding modules remain at the old private source locations.

The generated public package subpaths remain the supported imports. Private
`src/core-domains/physics/kits/*` paths were never a compatibility surface.

## Deferred Cutover

`n:simulation:physics` remains present while its consumers and execution
behavior are migrated through later work packages. Do not treat the new
contract foundation as proof that body state, collision detection, constraint
solving, queries, or concrete providers are complete. The final migration will
remove duplicate ownership and document exact consumer changes without runtime
forwarding aliases.
