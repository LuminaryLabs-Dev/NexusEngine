# 0.0.5 Render Texture

`0.0.5` adds the provider-neutral Texture package at `n:render:texture`. It
owns portable format records, exact logical Textures, typed views, mip plans,
stream requests, and proven subresource residency. It does not own source
images, decoding, materials, authored shadows, GPU handles, allocation,
upload, mip generation, attachment execution, eviction, or repair.

## Complete Import

```js
import { createEngine } from "nexusengine";
import { createRenderContractsDomain } from "nexusengine/domains/render/contracts";
import { createRenderLifecycleDomain } from "nexusengine/domains/render/lifecycle";
import { createRenderDeviceDomain } from "nexusengine/domains/render/device";
import { createRenderResourceDomain } from "nexusengine/domains/render/resource";
import { createRenderBufferDomain } from "nexusengine/domains/render/buffer";
import { createRenderTextureDomain } from "nexusengine/domains/render/texture";

const engine = createEngine({
  kits: [
    ...createRenderContractsDomain(),
    ...createRenderLifecycleDomain(),
    ...createRenderDeviceDomain(),
    ...createRenderResourceDomain(),
    ...createRenderBufferDomain(),
    ...createRenderTextureDomain()
  ]
});
```

## Contract

Texture Resource accepts exact Render Resource identities whose `kind` is
`texture`. The Resource descriptor must be a strict Texture descriptor and
must name a registered portable format. Supported dimensions are `2d`,
`cube`, and `2d-array`; unsupported dimensions fail before mutation. Usage,
format aspects, sample count, layer count, mip count, and attachment
qualification are validated together.

Source-provided mip plans name every level and immutable content identity.
Streaming selects a contiguous range from that exact plan, names the same
ordered content identities, and references an aligned bounded `copy-source`
Buffer range large enough for the portable texel footprint. Completion must
match the original request and a completed Device queue receipt byte for byte.

Residency admits only completed stream ranges. A stream identity can be
applied once, resident subresources must remain covered by admitted stream
evidence, and eviction updates only portable residency state. Provider memory
allocation and eviction remain external operations.

Every mutation requires an `operationId`. Exact replay returns the original
receipt, changed content under the same operation ID fails before mutation,
queries are read-only, snapshots are strict JSON-portable clones, and repeated
reset or load is stable.

There are no root forwarding exports, backend objects, implicit image decode,
implicit Buffer creation, provider execution, old aliases, or snapshot
coercion.
