# 0.0.5 Physics Lifecycle Cutover

The transitional Physics installation API combined installation, startup, and
shutdown. It marked Physics ready without a provider-readiness receipt. The
canonical lifecycle separates those responsibilities under
`n:physics:lifecycle`.

## Import Change

```js
// Removed. No forwarding export remains.
import { createPhysicsInstallationKit } from "nexusengine/domains/physics/installation";

// Canonical 0.0.5 import.
import { createPhysicsInstallationKit } from "nexusengine/domains/physics/lifecycle/installation";
```

The complete lifecycle can be imported from:

```js
import { createPhysicsLifecycleDomain } from "nexusengine/domains/physics/lifecycle";
```

## Behavioral Change

Old behavior:

```js
engine.n.physicsInstallation.install({ operationId: "install:1" });
// phase was immediately "ready"

engine.n.physicsInstallation.start({ operationId: "start:1" });
engine.n.physicsInstallation.stop({ operationId: "stop:1" });
```

New behavior:

```js
engine.n.physicsInstallation.install({
  operationId: "install:1",
  providerId: "my-provider"
});
// phase is "installed"

engine.n.physicsStartup.begin({ operationId: "startup:begin:1" });
engine.n.physicsStartup.complete({
  operationId: "startup:complete:1",
  providerReceipt: { providerId: "my-provider", ready: true }
});
// phase is now "ready"

engine.n.physicsShutdown.begin({ operationId: "shutdown:begin:1" });
engine.n.physicsShutdown.complete({
  operationId: "shutdown:complete:1",
  providerReceipt: { providerId: "my-provider", ready: false }
});
// phase returns to "installed"
```

## Atomic APIs

| Capability | Public import | Ownership |
| --- | --- | --- |
| Installation | `nexusengine/domains/physics/lifecycle/installation` | Aggregate phase and provider identity |
| Startup | `nexusengine/domains/physics/lifecycle/startup` | Startup request and readiness receipt |
| Step | `nexusengine/domains/physics/lifecycle/step` | Strict step ordering and frame receipt |
| Shutdown | `nexusengine/domains/physics/lifecycle/shutdown` | Stop request and provider receipt |
| Reset | `nexusengine/domains/physics/lifecycle/reset` | Atomic composed lifecycle reset |
| Snapshot | `nexusengine/domains/physics/lifecycle/snapshot` | Portable composed capture and restore |

Every mutation requires an `operationId`. Exact replay returns the original
receipt. Reusing an ID with different content fails before mutation. Reset and
restore roll back every touched public lifecycle API when a component fails.

This cutover does not add a solver or concrete provider. Those remain separate
provider packages and later evidence-gated work.
