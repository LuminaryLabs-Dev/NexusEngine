# NexusEngine 0.0.4 Release Goal

Produce one clean, reproducible NexusEngine commit that contains the consolidated
Core and complete `n:build` release surface, passes clean consumer and showcase
proof, and can become both remote `main` and immutable branch `0.0.4` after the
required approvals.

```txt
clean clone
-> verified Web dependency closure
-> Android XR and Windows PCVR package proof
-> exact-SHA Kits, Editor, Simulator, and The Open Above installs
-> repeated composition/build no-op and restart restoration
-> committed-SHA local and hosted gates
-> explicit main push approval
-> exact release approval
-> main and 0.0.4 point to the same commit
```

Hardware execution, deployment, npm publication, tags, GitHub Releases, and
Google Docs mutation are separate gated tasks and are not implied by package
proof.
